# اللؤلؤ الأسود — الموقع

النسخة الأولى من الموقع، مبنية بـ Next.js وTailwind CSS وGSAP، وتعتمد على تصميم Figma (الصفحة الرئيسية).

## التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح http://localhost:3000

## ما هو موجود حالياً

- التخطيط العام: الهيدر والفوتر بالاتجاه العربي RTL.
- الصفحة الرئيسية: الهيرو وأقسام "من نحن" و"ماذا نفعل؟" و"كيف نعمل؟" وقسم الدعوة للتواصل.
- حركة خفيفة في الهيرو فقط، وتُلغى تلقائياً إذا فعّل الزائر "تقليل الحركة" في جهازه.

## ما ينقص (الخطوة التالية)

- صفحات: من نحن، خدماتنا، منظومتنا، تواصل معنا (الروابط موجودة لكن الصفحات لم تُبنَ بعد).
- نموذج التواصل.
- بيانات ناقصة: الهاتف والسجل التجاري، ويُعدّلان في الفوتر وفي الصفحة الرئيسية.
- الصفحات القانونية: سياسة الخصوصية والشروط والأحكام.

## الشعار والفيديو

- **الشعار:** صدّره من Figma كملف SVG (اختر الشعار ← Export ← SVG)، وسمّه `logo.svg` وضعه في مجلد `public`.
- **فيديو الهيرو:** موجود في `public/hero.mp4`. يعمل تلقائياً بدون صوت، ويتوقف عند تفعيل "تقليل الحركة".
